# VS-гид для Z Route: Redemption

Офлайн-приложение-гайд по еженедельному событию **VS («Состязание альянсов», Victory Showdown)**:
шесть фаз, очки за действия, окна «Готовности к миссии», калькулятор с бонусами ветки VS,
награды и локальные напоминания. Android 5.0+, без рекламы, без аналитики, без сети —
интернет нужен только для проверки обновлений.

## Скачать

**[Последняя версия →](https://github.com/Suslyandia/ZRouteVSguide/releases/latest)**

| Файл | Для чего |
|---|---|
| `ZRoute-VS-guide.apk` | установка на Android 5.0 и новее |
| `vs-guide.html` | всё приложение одним файлом, открывается в браузере без установки |

Приложение обновляется само: **Ещё → Обновления → Проверить обновления**.
Гайд при этом работает офлайн, сеть нужна только для проверки версии и скачивания APK.
